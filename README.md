# photo-slide

フォトスライドショー & タグ管理アプリケーション

## 概要

`photo-slide` は、画像フォルダを読み込み、タグ付けやフィルタリングを行いながら快適に画像を閲覧できるデスクトップアプリケーションです。Electron をベースに構築されています。

## 主な機能

- **フォルダブラウズ**: 指定したフォルダ内の画像を一覧表示。
- **スライドショー**: 左右キーまたはマウス操作で画像を切り替え。
- **タグ管理**:
  - 画像ごとにカスタムタグを追加・削除。
  - 既存のタグからサジェストを表示。
- **強力なフィルタリング**:
  - 特定のタグを含む、または除外する画像のみを表示。
  - 複数タグによる組み合わせフィルタリングが可能。
- **表示モード**:
  - 画面に収める、幅合わせ、高さ合わせ、オリジナルサイズの4つのモードを搭載。
- **ファイル操作**:
  - ファイル名の変更（リネーム）。
  - フルパスのコピー。
  - ファイル自体のコピー（クリップボードへ）。

## セットアップと起動

### 準備

Node.js がインストールされている必要があります。

### インストール

#### Homebrew (macOS)

[blue1st/homebrew-taps](https://github.com/blue1st/homebrew-taps) を利用して、以下のコマンドでインストールできます：

```bash
brew install --cask blue1st/taps/photo-slide
```

一度 tap している場合は、以下のようにも実行できます：

```bash
brew tap blue1st/taps
brew install --cask photo-slide
```

#### ソースからビルド

```bash
npm install
```

### アプリの起動

```bash
npm start
```

## 使い方

1. 「フォルダを開く」ボタンから画像のあるフォルダを選択します。
2. 左右キー（または `A`/`D` キー）で画像を切り替えます。
3. タグ入力欄からタグを追加できます。
4. 下部のタグリストをクリックすることで、表示する画像をフィルタリングできます。
   - 1回クリック: そのタグを**含む**画像を表示
   - 2回クリック: そのタグを**除外**する画像を表示
   - 3回クリック: フィルタを解除

## キーボードショートカット

- `ArrowRight` / `D`: 次の画像
- `ArrowLeft` / `A`: 前の画像
- `ArrowUp` / `W`: 表示モードの切り替え
- `Enter` (タグ入力中): タグの追加

## トラブルシューティング

### 「壊れているため開けません」と表示される場合 (macOS)

GitHub Releases からダウンロードした `.app` や `.dmg` を開く際に、「“PhotoSlide”は壊れているため開けません。ゴミ箱に入れる必要があります。」という警告が出ることがあります。これは、macOS の Gatekeeper が未署名のアプリケーションをブロックする仕様によるものです。

**解決方法:**

1. ダウンロードした `PhotoSlide.app` を「アプリケーション」フォルダ (`/Applications`) に配置します。
2. ターミナルを開き、以下のコマンドを実行して隔離属性 (Quarantine) を解除します。
   ```bash
   xattr -cr "/Applications/PhotoSlide.app"
   ```
3. その後、通常通りダブルクリックで起動できるようになります。
